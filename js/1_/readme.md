1. Создайте 2 html-документа: login.html и main.html.
2. Разместите на странице форму с двумя текстовыми полями для ввода
   логина (типа text) и пароля (типа password) и кнопку «Вход».
3. Создайте функцию - обработчик события нажатия на кнопку «Вход».
   Допустим, доступ на сайт получает только пользователь с логином student и
   паролем student. При правильно введенном логине И пароле функция выдаст
   пользователю сообщение «Добро пожаловать, %username%!», а затем откроет
   в этом же окне страницу main.htm (window.location.href= “main.html ”).
4. Если в логине или пароле содержится ошибка, пользователь должен
   увидеть сообщение «Неправильный логин или пароль!». В таком случае
   пользователь остается на странице авторизации для исправления входных
   данных.
