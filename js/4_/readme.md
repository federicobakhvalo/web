1. Создайте html-документ index.html.
2. Расположите на странице форму с двумя полями для ввода «Число
   строк» и «Число столбцов» (типа text) и кнопкой «Создать».
3. Создать обработчик событий onClick для кнопки «Создать», который
   выводит на экран таблицу с заданным количеством строк и столбцов. Таблица
   должна быть заполнена случайными целыми числами от 0 до 100,
   отсортированными по столбцам по возрастанию.
