1. Создайте html-документ index.html.
2. На странице создайте форму со следующими элементами:
   a. Текст «Отобразить:»
   b. 3 флажка (checkbox) со значениями «Дату и время», «Список», «Абзац
   текста красного цвета»
   c. Кнопку «Показать»
3. Создайте обработчик события onClick для кнопки «Показать». При
   нажатии на кнопку в зависимости от выбранного флажка или их совокупности
   (проверка на выбор флажка: document.getElementById().checked) на странице
   отображаются:
   a. Текущая дата и время;
   b. Маркированный список из первых трех предметов Вашего
   расписания;
   c. Абзац текста красного цвета.
