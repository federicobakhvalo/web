1. Создайте html-документ index.html.
2. На странице создайте форму со следующими элементами для
   обратной связи:
   ₋ Выпадающий список select. Первый пункт списка – пустой, второй –
   «Благодарность», третий – «Отзыв», четвертый – «Жалобу».
   ₋ Текстовое поле textarea с текстом по умолчанию «Текст сообщения…»
3. Для выпадающего списка создайте обработчик события onChange,
   который реагирует на изменение выбранного элемента в списке:
   ₋ При выборе пункта «Благодарность» текст в текстовом поле (value)
   заменяется на текущую дату и время и фразу «Вы великолепны! Ваш код
   работает без ошибок!»
   ₋ При выборе пункта «Отзыв» текст в текстовом поле (value) заменяется
   на текущую дату и время и фразу «Вы все еще великолепны, но у меня есть
   пара конструктивных замечаний.»
   ₋ При выборе пункта «Жалобу» текст в текстовом поле (value)
   заменяется на текущую дату и время и фразу «К сожаленью, День Рожденья
   только раз в году»
   (Чтобы получить значение value выбранного элемента в выпадающем
   списке, необходимо:
   а) Сначала использовать свойство selectedIndex, которое возвращает
   число, обозначающее порядковый номер выбранного элемента, нумерация
   начинается с нуля: var n =
   document.getElementById("list").options.selectedIndex;
   б) Затем использовать метод options: var txt
   =document.getElementById("list").options[n].value;).
