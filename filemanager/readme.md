Задание:
Разработать веб-приложение «Интерактивный менеджер файлов»,
состоящее из двух частей:
1.Клиентская часть (Frontend): одностраничное приложение (SPA),
реализующее пользовательский интерфейс.
2.Серверная часть (Backend): REST API для хранения и обработки данных.
Функционал клиентской части (Frontend)
₋ Загрузка файла: реализовать загрузку только через стандартное поле
<input type="file">. Drag-and-Drop не требуется.
₋ Отображение списка: показать таблицу или список с названиями всех
загруженных файлов.
₋ Удаление файла: для каждого файла добавить кнопку «Удалить», которая
отправляет запрос на сервер.
₋ Редактирование названия: для каждого файла добавить кнопку
«Переименовать» или сделать название редактируемым полем, чтобы изменить
только имя файла.
₋ Загрузка нового файла: после успешной загрузки файл должен
автоматически появиться в списке без перезагрузки страницы.
Функционал серверной части (Backend)
Необходимо разработатьREST API с помощью Node.js и Express.js, которое
взаимодействует с базой данных MongoDB (через Mongoose).
Эндпоинты API:
₋ GET /api/files — получить список всех файлов (только их названия и ID).
₋ POST /api/files — загрузить новый файл. Сервер должен принять файл,
сохранить его на диск, а в базу данных записать только его имя и путь.
₋ PUT /api/files/:id — обновить название файла по его ID.
₋ DELETE /api/files/:id — удалить файл по его ID (удалить запись из БД и
сам файл с диска).

Технические требования
Для клиентской части (Frontend)
₋ Технологии: чистый JavaScript, HTML, CSS. Фреймворки использовать
не нужно.
₋ Работа с DOM: динамически добавлять новые файлы в список при
загрузке и удалять их из списка при удалении.
₋ Сетевые запросы: взаимодействие с сервером черезfetch(). Обязательно
использовать async/await для обработки запросов.
₋ Код: весь JavaScript-код можно разместить в одном файле script.js.
Разделение на модули не требуется.
Для серверной части (Backend)
₋ Технологии: Node.js, Express.js.
₋ База данных: MongoDB. Использовать библиотеку Mongoose для
работы со схемой данных.
₋ Загрузка файлов: использовать библиотеку Multer для обработки
загрузки файлов. Файлы сохранять в папку на сервере (например, uploads/).
₋ Схема данных (Mongoose): достаточно хранить всего два поля:
filename (строка) — имя файла и path (строка) — путь к файлу на диске сервера.
