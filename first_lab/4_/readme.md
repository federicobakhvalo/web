Решите обе задачи последовательно, пропишите соответствующий CSSкод в файле styles.css, обеспечив выполнение требований каждой задачи.
№ Задача Описание

1. Анимация
   нескольких
   объектов с
   синхронизацией
   Создайте сцену, состоящую из пяти различных
   геометрических фигур (квадраты, круги,
   треугольники). Каждая фигура должна иметь
   уникальную траекторию движения и
   продолжительность анимации. Однако при
   достижении определенного момента все фигуры
   должны синхронно вернуться в исходное
   положение.
   Что нужно учесть:
   • Использование ключевых кадров (@keyframes)
   для каждой фигуры.
   • Настройка задержек и продолжительности для
   каждой анимации.
   • Синхронизация возврата всех фигур в одно и то
   же время.
2. Интерактивная
   анимация на основе
   событий
   Создайте анимацию, которая реагирует на
   события пользователя. Например, при наведении
   курсора на элемент, он начинает вращаться,
   увеличивать или уменьшать размер. При клике на
   этот элемент анимация останавливается и
   происходит обратное действие.
   Что нужно учесть:
   • Работа с псевдоклассами :hover и событиями
   click.
   • Создание анимаций для каждого возможного
   состояния элемента.
   • Поддержание гладкости и непрерывности
   анимаций.
