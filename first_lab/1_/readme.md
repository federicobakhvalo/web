2. Наполнение файла HTML
   Создайте простую HTML-структуру, включающую следующее:
   ₋ Шапку с навигационным меню.
   ₋ Несколько секций с контентом.
   ₋ Боковую панель с формой.
   ₋ Нумерованный список.
3. Создание файла CSS
4. Создайте новый файл с именем styles.css в той же папке.
5. Реализуйте следующие требования задания:
   ₋ Используйте псевдокласс :hover для изменения цвета фона кнопки
   при наведении курсора.
   ₋ Примените псевдокласс :active для выделения текущего активного
   пункта навигационного меню.
   ₋ Настройте стиль для посещённых ссылок с помощью псевдокласса
   :visited.
   ₋ Реализуйте интерактивность, скрывая или отображая
   дополнительные элементы при помощи псевдоклассов :checked и
   :not(:checked) для чекбоксов или радио-кнопок.
   ₋ Измените цвет текущей активной вкладки с помощью
   псевдокласса :target.
   ₋ Добавьте стили, чтобы при получении фокуса полем ввода оно
   выделялось другим цветом рамки или фона.
   ₋ Используйте псевдокласс :nth-of-type() для оформления каждого
   третьего элемента в списке.
