Разработать адаптивный макет главной страницы новостного сайта,
используя Flexbox для организации структуры и позиционирования
элементов.
Основные требования:

1. Шапка сайта: Должна содержать логотип, главное меню и строку
   поиска. Шапка должна оставаться фиксированной при прокрутке страницы.
   ₋ Логотип: margin-right: auto; (для отделения от меню)
   ₋ Меню: justify-content: flex-end; (выравнивание по правому краю)
   ₋ Поисковая строка: width: 100%; (полоса на всю ширину)
2. Главная область: Включает ленту новостей, боковую колонку с
   популярными статьями и рекламными баннерами.
   ₋ Лента новостей: flex-grow: 1; (занимает оставшееся пространство)
   ₋ Боковая колонка: flex-basis: 33.33%; max-width: 250px;
   (фиксированная ширина на десктопе)
3. Нижняя часть: Подвал сайта с контактной информацией, ссылками
   на социальные сети и копирайтом.
   ₋ Контакты и ссылки: justify-content: center; align-items: center;
   (центровка по горизонтали и вертикали)
   Дополнительные условия:
   ₋ Макет должен быть адаптивным, то есть хорошо выглядеть на
   экранах разных размеров (десктоп, планшет, мобильный телефон).
   ₋ Важно использовать свойства Flexbox для правильного
   расположения и выравнивания элементов, учитывая особенности мобильных
   устройств.
   ₋ Внешний вид должен соответствовать современным стандартам
   дизайна и обеспечивать удобство использования.
