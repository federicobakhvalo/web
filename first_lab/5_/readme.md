Создание 3Dэффектов для
карточек
товаров
Создайте макет карточки товара, которая при
наведении поворачивается в трехмерном
пространстве, открывая дополнительную
информацию о продукте на обратной стороне.
Что нужно учесть:
• Использование свойств perspective, rotateY и
translateZ для создания 3D-эффекта.
• Добавление теней с помощью box-shadow для
усиления глубины.
• Работа с псевдо-классом :hover для активации
трансформации.
(Карточка товара выглядит плоской, пока на нее не
навели курсор).
