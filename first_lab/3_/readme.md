Выполняйте каждую задачу последовательно, прописывая нужные CSSстили в файле styles.css.
№ Задача Описание

1. Базовый
   переход цвета
   Создайте кнопку, которая при наведении меняет цвет
   фона с помощью CSS-перехода. Установите
   длительность перехода 0.5 секунды.
2. Переход
   размеров
   Изобразите квадрат, который увеличивается при
   наведении на него курсора. Переход должен длиться 1
   секунду.
3. Анимация
   движения
   Создайте блок, который перемещается вправо на 100
   пикселей при наведении на него. Время перехода — 500
   мс.
4. Контроль
   задержки
   Добавь задержку перед началом перехода. Например,
   пусть блок начнёт движение только спустя 300
   миллисекунд после наведения.
